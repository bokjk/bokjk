## 몽글 터미널

<picture>
  <source media="(max-width: 600px) and (prefers-color-scheme: dark)" srcset="assets/terminal-dark-mobile.svg" />
  <source media="(max-width: 600px)" srcset="assets/terminal-light-mobile.svg" />
  <source media="(prefers-color-scheme: dark)" srcset="assets/terminal-dark.svg" />
  <img src="assets/terminal-light.svg" width="100%" alt="몽글 터미널 — 작업은 그대로. 어디서든, 이어서" />
</picture>

**여러 프로젝트의 터미널을 모으고, 내 방식대로 나누고, 다른 기기에서 이어서.**

작업 그룹과 탭으로 정리하고 워크트리로 작업을 분리합니다. 자리를 옮겨도 켜져 있는 PC의 터미널에 다시 연결할 수 있습니다.

<p align="center">
  <picture>
    <source media="(max-width: 600px)" srcset="assets/mongle-terminal-mobile.png" />
    <img src="assets/mongle-terminal-desktop.png" width="100%" alt="몽글 터미널 실제 앱 화면 — 넓은 화면에서는 데스크톱 분할 보기, 좁은 화면에서는 모바일 브라우저 예시" />
  </picture>
</p>

<sub>공개 배포 안내의 예제 프로젝트 화면입니다. 데스크톱은 0.3.8, 모바일은 휴대폰 크기의 브라우저 데모이며 실물 기기 캡처가 아닙니다.</sub>

- **모아서 정리** — 폴더가 다른 터미널도 작업 그룹 하나에.
- **나눠서 집중** — 탭·화면 분할·워크트리로 각자의 작업을.
- **어디서든 계속** — Tailscale로 다른 PC나 휴대폰에서 연결.

<p>
  <a href="https://github.com/bokjk/mongle-terminal-releases/releases/latest"><img src="assets/download-terminal.svg" width="226" height="48" alt="몽글 터미널 최신 Windows 설치 파일 다운로드" /></a>
  <a href="https://github.com/bokjk/mongle-terminal-releases#readme"><img src="assets/read-guide.svg" width="202" height="48" alt="몽글 터미널 사용법 살펴보기" /></a>
</p>

Windows 미리보기 버전 · 원격 연결에는 Tailscale과 켜져 있는 작업 PC가 필요합니다.
